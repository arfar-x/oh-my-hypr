# oh-my-hypr

Personal customizations for a stock [end-4/dots-hyprland](https://github.com/end-4/dots-hyprland) (illogical-impulse) install. `config/` mirrors `~/.config`; only files that differ from upstream are included.

Apply: `./install.sh` (idempotent: overwrites only changed files, creates no backups or leftovers). It also installs the packages the customizations need (power-profiles-daemon and hypridle/brightnessctl/jq for the Idle settings; kitty, cmatrix, genact, cbonsai and hollywood for the screensaver, the last two from the AUR), using sudo pacman and yay/paru, and enables power-profiles-daemon. Use `./install.sh --skip-deps` to skip that.

Remove everything again: `./uninstall.sh` (`--dry-run` to preview). Restores the stock end-4 version of every file, deletes files this repo added, and has end-4 regenerate the terminal palette. Needs network access to fetch the stock files.

## What's in it
- **hypr/custom/keybinds.lua** – Ctrl+B tmux-style resize mode (arrows, Ctrl+Arrow = bigger steps, Esc/Enter/Ctrl+B exit); hold Super+X + left-drag to resize; Super+Up maximize, Super+Down minimize, Super+Shift+Z restore, Super+D show desktop, Super+Z float/tile; Alt+Tab window picker (hold Alt, Tab cycles, release focuses); Super+Tab workspace cycle with overview preview; Super+A fuzzel. Pressing any key while Super is held cancels the tap-Super-to-open-launcher action (upstream's catchall bind is not allowed outside submaps in the Lua API, so a raw key-event handler does it; Super+mouse drag/scroll binds cancel it too).
- **hypr/custom/per-app-rules.lua / rules.lua** – translucency + blur for VS Code, Kitty, Telegram, Hermes via one shared `glass()` helper (80% base; VS Code is 92% and Telegram and Hermes 90% when focused for readability); fuzzel, overview and Alt+Tab picker layer blur.
- **hypr/custom/scripts/** – minimize / show-desktop state handling. Focusing a minimized window (dock click, Alt+Tab) restores it via a `window.active` hook in keybinds.lua. Clicking (not merely hovering) a tiled window parks overlapping floating windows the same way (floating always draws above tiled in Hyprland). Minimize plays a shrink-to-dock effect (quickshell minimizeFx); Super+Z resizes to 70% and centres when floating so the toggle animates, and tags the window `zfloat`: a rotating gradient border (primary/tertiary/secondary of the wallpaper palette, `borderangle` loop animation in general.lua) comes from a rule appended to the matugen `hyprland/colors.lua` template, so it follows the wallpaper; it shows after the next wallpaper/palette regeneration.
- **hypr/custom/scripts/display-mode.sh** – applies a display mode with `hyprctl eval hl.monitor{...}` (`join|mirror|primary|secondary`, `info` prints the monitors and current mode). Primary is the built-in panel (eDP/LVDS/DSI) or the first monitor. Steps are ordered so two enabled monitors never share space, because Hyprland warns "Monitor X overlaps with other monitor(s)" even for a momentary overlap. The result is shown as the layout OSD pill with an icon; in the single-display modes it waits until quickshell has redrawn on the remaining screen. Not persisted: a reload goes back to the configured layout.
- **hypr/custom/variables.lua** – Super+Enter / Ctrl+Alt+T open kitty first (upstream prefers foot, which would bypass the kitty look and rules).
- **hypr/custom/general.lua** – window move/resize animation curve.
- **hypr/hyprland/{general,keybinds}.lua, hyprlock.conf** – small edits to upstream (scroll factor, Super+A, workspace move keys, 12h lock clock).
- **quickshell/ii** – overview with browsable app list (IdleAppBrowser), category chips, pinned apps, letter sections.
- **quickshell/ii/modules/ii/altTab** – Alt+Tab picker: live thumbnails, minimized windows included, hover close button, frosted background, one picker per monitor with a short fade; registered in panelFamilies/IllogicalImpulseFamily.qml.
- **quickshell/ii/modules/ii/displayMode** – Super+P display mode picker in the Alt+Tab card style, with drawn two-monitor icons: Join Displays (extend), Mirror, Primary Only, Secondary Only. Hold Super, P (or Super+Left/Right) cycles, releasing Super applies, Esc cancels; it opens on the current mode so a quick tap changes nothing. Driven over IPC (`displayMode open|next|prev|left|right|confirm|cancel`) from a submap in `hypr/custom/keybinds.lua`; registered in panelFamilies/IllogicalImpulseFamily.qml. Window pin moves to Super+Alt+P. Also available as a `displayMode` quick toggle in the right sidebar's Android-style panel (add it in the panel's edit mode).
- **quickshell/ii/modules/ii/minimizeFx** – snapshot of the window shrinks toward the dock when minimized; called over IPC by window-state.sh.
- **quickshell/ii/modules/ii/bar/NetworkPopup.qml** – separate network button in the bar (replaces the icon inside the right sidebar button); click opens a popup with the current wired connection on top (the active Wi-Fi network is listed first), the Wi-Fi switch, nearby networks (connect, password prompt) and VPN on/off switches. It opens on the screen whose button was clicked (multi-monitor safe), slides in without blinking, and uses a fixed-size window with an input mask so it never resizes while open; `custom/rules.lua` turns off Hyprland's own layer animation for it. A VPN-connected icon shows in the bar while any VPN/tunnel is up (NetworkManager VPN/WireGuard or tun/wg/ppp-style interfaces), and a critical notification fires when it drops. VPN state, listing and toggle live in services/Network.qml; BarContent.qml and GlobalStates.qml carry the small wiring edits.
- **quickshell/ii/services/ai/OpenRouterApiStrategy.qml** – OpenRouter provider for the Super+B AI sidebar. The full OpenRouter catalogue is fetched at startup and searchable with `/model`; per-chat cost chip and `/credits`; `/reasoning off|low|medium|high`; `/tool search` enables OpenRouter web search; `/attach` sends images and PDFs. API keys can also come from `OPENROUTER_API_KEY` / `GEMINI_API_KEY` / `MISTRAL_API_KEY` (a key saved with `/key` wins). Small edits in services/Ai.qml, services/ai/{AiModel,ApiStrategy,OpenAiApiStrategy}.qml and sidebarLeft/AiChat.qml.
- **quickshell/ii/modules/common/models/WorkspaceModel.qml** – the bar no longer shows a stray `special` pill when no special workspace is open (upstream falls back to the name `special` whenever the monitor lookup returns nothing).
- **quickshell/ii/modules/settings/GeneralConfig.qml, modules/common/Config.qml, services/IdleManager.qml, scripts/idle/apply.sh** – Super+I > General > Idle: per power profile (power saver / balanced / performance), minutes until dim (with dimmed brightness %), screensaver, lock, screen off and suspend (0 disables a step). IdleManager regenerates `hypr/hypridle.conf` and restarts hypridle when the active profile or a value changes. Needs power-profiles-daemon.
- **quickshell/ii/modules/ii/onScreenDisplay/** – changing the power profile shows the same OSD pill as the keyboard layout, with the profile icon and "Switched to ...".
- **quickshell/ii/modules/ii/onScreenDisplay/** – Super+Space shows the new keyboard layout as a minimal OSD pill (`indicators/LayoutIndicator.qml`, IPC `osdVolume layout <label>`, driven by `hypr/custom/scripts/switch-layout.sh`) instead of a notification. `OnScreenDisplay.qml` also gives every OSD indicator (volume, brightness, gamma, layout) one shared fade + spring-scale animation and keeps the window alive briefly so the exit animation plays; GlobalStates.qml carries `osdLayoutLabel`.
- **quickshell/ii/modules/ii/onScreenDisplay/** – IPC `osdVolume layoutIcon <icon> <label>` shows the same pill with a Material symbol before the label (used by the display mode picker). The OSD falls back to the first remaining screen when Hyprland has no focused monitor, which happens after a monitor is turned off.
- **quickshell/ii/services/HyprlandXkb.qml** – the bar's keyboard-layout indicator follows only the main keyboard. Hyprland emits `activelayout` per input device, and devices that register as keyboards (e.g. Bluetooth headsets) can sit on a different layout and made the indicator show the wrong one.
- **quickshell/ii/modules/ii/bar/PublicIpWidget.qml** + **services/PublicIp.qml** – public IP widget in the right side of the bar: country flag and IP from a default source (checked every 5 minutes, left-click refreshes, right-click copies, notifies when the IP changes). Hovering shows location/ISP and checks the other sources for comparison (30s timeout, per-source errors). Sources and default are set in PublicIp.qml; BarContent.qml carries the small wiring edit.
- **state/terminal** – kitty-theme.conf + sequences.txt, the generated terminal palette (kitty colors and fish/starship color sequences) pinned so kitty and fish look identical on a new machine. The kitty and fish configs themselves are stock end-4; kitty's 80% opacity + blur comes from the `glass()` helper in per-app-rules.lua. end-4 overwrites the palette when the wallpaper/theme changes.

Requires fuzzel, kitty, fish, starship, eza, ttf-jetbrains-mono-nerd. Written against dots-hyprland commit 2f2a376.
- **quickshell/ii/scripts/idle/screensaver.sh, hypr/custom/keybinds.lua, hypr/custom/rules.lua** – terminal screensaver. Ctrl+Super+Z toggles it, and the Idle settings can start it after N idle minutes (a hypridle step before lock). It puts an overlay panel (kitty `panel`, above the bar) on every monitor over your desktop, blurred and darkened by the profile's dimmed brightness (or the wallpaper, see "Screensaver backdrop"), running cmatrix, cbonsai (one large tree growing step by step), hollywood or genact; "Random" picks among the installed ones. While it runs a Hyprland `screensaver` submap makes any key or mouse button stop it, and moving the mouse stops it too, whatever the animation does with input. `rules.lua` blurs the panel's layer.
